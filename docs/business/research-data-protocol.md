# Research Data Protocol

本协议适用于 Founder Log 之外的访谈、真实 Seed、Concierge 交付和价格实验。它是产品早期
隐私基线，不替代所在地法律意见；首次外部研究前必须逐项执行。

## 默认原则

- 只收集回答当前产品决策所需的最少信息。
- 默认不录音、不录像，不收集真实姓名、账号、联系方式、凭据或第三方私密内容。
- 原始研究资料不进入 Git、Issue、PR、Trace、测试、模型 Prompt 样例或公开文档。
- 参与研究不等于同意训练模型、公开引用、长期保存或将其账号连接产品。
- 删除请求优先于研究便利；参与者可随时停止且不影响已获得的服务。

## 访谈前同意

开始前用普通语言说明并获得明确同意：

> 我们正在研究“碎片想法如何变成可用成果”，本次约 30 分钟。默认只做文字笔记，不录音。
> 笔记只用于产品判断，不会包含在公开仓库；公开时只使用无法识别个人的聚合结论。你可以跳过
> 任何问题、随时结束，并要求删除笔记。若要把真实 Seed 交给 AI 辅助处理，我们会另外说明
> 使用的服务、可能发送的数据和删除时间，再单独征得同意。

记录：

- consent date；
- allowed uses：`interview notes / AI-assisted concierge / anonymized quote / follow-up`；
- recording：默认 `no`；
- deletion date；
- participant request or restriction。

不得把沉默、继续聊天或接受产品演示视为同意。

## 标识与最小采集

- 使用随机参与者 ID（如 `P-004`），不把姓名或社交账号写进分析笔记。
- 招募联系方式与研究笔记分开保存；公开聚合表不保留可回连映射。
- 只记录最近真实行为、工具、频率、耗时区间、失败、替代品、复用和价格回应。
- 不主动采集身份证、精确住址、财务账号、健康/法律秘密、工作单位机密、未成年信息、
  登录凭据或 API Token。
- Seed 含他人信息、客户资料、未公开商业内容或秘密时，要求参与者先脱敏；无法脱敏则拒绝接收。

## 私有存储与访问

- 原始笔记和联系映射存入仓库外、设备加密且有访问控制的私有资料库。
- 当前阶段只允许项目所有者访问；增加成员前重新列出访问者和用途。
- 不使用公共分享链接，不把完整原始资料粘贴进 Codex 任务或 Subagent Prompt。
- 需要 AI-assisted Concierge 时，先记录供应商、数据字段、账号设置和删除方式，只发送完成
  当前任务所需的脱敏片段。不同意 AI 处理时提供纯人工路径或停止该任务。

仓库 `.gitignore` 防误提交 `.private-research/`，但忽略规则不是安全存储方案。

## 保留与删除

| Data | Default retention |
|---|---|
| 招募但未参与的联系方式 | 招募结束后 30 天 |
| 联系映射 | 最后一次研究互动后 90 天 |
| 原始访谈笔记 | 访谈后 90 天 |
| 经同意的临时录音 | 转写核对后立即删除，最长 7 天 |
| 真实 Seed 与 Concierge 工作副本 | 交付/实验结束后 30 天 |
| 去标识聚合结论和决策 | 可长期保留，并记录样本与日期 |
| 付款/发票记录 | 按适用财税要求单独保存 |

每周研究复盘时执行到期删除并记录“删除完成”，不保留被删除内容的副本。收到删除请求后，
在 7 天内删除可识别原始资料并确认；已无法回连个人的聚合统计可以保留。

## 公开与进入仓库的门槛

- 只有去标识的聚合结论可进入仓库，默认至少汇总 5 位参与者后再公布模式。
- 小于 5 人的结果只能标为个案，不描述可能识别个人的组合特征。
- 原话引用需要额外的逐字公开同意；否则只做不具识别性的意译。
- 公开记录包含样本量、招募区间、问题版本、反例和限制，不公布原始 Prompt/Trace。
- 合成测试数据必须重新创作，不能仅替换真实姓名后继续使用真实内容。

## 异常处理

若资料误入 Git、共享链接、日志或未经同意的 AI 服务：

1. 立即停止传播和相关实验；
2. 撤销链接/凭据并从可控位置移除；
3. 保存不含原始私密内容的事件时间线；
4. 判断受影响参与者并及时告知；
5. 增加回归防护后才恢复研究。

任何不确定的资料都按私密处理。便利不能覆盖参与者意愿。

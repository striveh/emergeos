# RFC

RFC 用于讨论影响 public contract、产品宪章、Self Model、权限、外部行动、
核心依赖或跨模块架构的变更。

流程：

```text
Draft → Discussion → Experiment → Accepted | Rejected | Withdrawn
```

RFC 被接受并落地后，由 ADR 记录最终采用的决定；RFC 历史不回写。
